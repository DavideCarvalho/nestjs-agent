- Channels: a card whose `confirmation.link` is set is sent as one message with the link in full, `texts.linkInstruction` and how long it works (`texts.linkValidity`, from `ChannelProposal.expiresAt`) — no buttons, no reply commands. `AgentChannelsService.follow(address, run)` delivers a run the channel did not start (a turn the server continued) to the conversation its page context names, once per run, durably under the durable executor; the module binds `AGENT_CHANNEL_FOLLOWER` to it and is now global. New `onTurnEnded` hook (`ChannelTurnEnded`, `ChannelTurnOutcome`): called once per message, resume or follow job this process ran — replied, failed, timeout, blocked, parked, stopped, handled or interrupted.
- React: `useActionProposals` takes `onAdmitted(proposalIds)` for outcomes newly admitted; `useAgentChat().followServerTurn()` streams a turn the server started on the thread (after a sign-in finished elsewhere, say), called on its own when the chat's proposals see a new outcome.
